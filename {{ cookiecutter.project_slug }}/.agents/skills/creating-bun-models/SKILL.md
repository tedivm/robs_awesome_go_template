## Quick start

Create models in `internal/model/` by embedding `BaseModel` and adding `bun` tags. Always create a matching migration in `migrations/`. Use explicit column types — no magic type inference.

## Workflow

1. Create a file in `internal/model/` (one file per model)
2. Embed `BaseModel` and add `bun:"table:name,alias:x"` tag
3. Add fields with `bun` tags for type and constraints, `json` tags for serialization
4. Create a matching migration with `goose -dir migrations create <name> sql`
5. Verify the migration runs against both SQLite (dev) and PostgreSQL (prod)

### BaseModel

```go
// internal/model/base.go
package model

import (
    "context"
    "time"

    "github.com/google/uuid"
    "github.com/uptrace/bun"
)

type BaseModel struct {
    bun.BaseModel `bun:"table:base,alias:b"`

    ID        uuid.UUID      `bun:"type:uuid,pk" json:"id"`
    CreatedAt time.Time      `bun:"type:timestamptz,notnull,default:current_timestamp" json:"created_at"`
    UpdatedAt time.Time      `bun:"type:timestamptz,notnull,default:current_timestamp" json:"updated_at"`
    DeletedAt *time.Time     `bun:"type:timestamptz,soft_delete" json:"-"`
}

func (b *BaseModel) BeforeInsert(ctx context.Context) error {
    if b.ID == uuid.Nil {
        b.ID = uuid.New()
    }
    return nil
}
```

**Key behaviors:**
- UUID primary keys — **always set `ID: uuid.New()` explicitly in Create\* functions**. The `BeforeInsert` hook on `*BaseModel` may not fire when BaseModel is embedded by value in another struct (bun's hook dispatch on promoted methods is unreliable). Treat the hook as a safety net only.
- `CreatedAt` and `UpdatedAt` with database defaults
- `DeletedAt` enables soft deletes — bun filters deleted rows automatically
- `json:"-"` on `DeletedAt` hides it from API responses

### Creating a new model

```go
// internal/model/item.go
package model

import (
    "time"

    "github.com/google/uuid"
    "github.com/uptrace/bun"
)

type Item struct {
    BaseModel `bun:"table:items,alias:i"`

    Name        string    `bun:"type:varchar(255),notnull" json:"name"`
    Description string    `bun:"type:text" json:"description"`
    Status      string    `bun:"type:varchar(50),default:active" json:"status"`
    CreatedBy   uuid.UUID `bun:"type:uuid" json:"created_by"`
}
```

### Bun tag reference

| Tag | Description | Example |
|-----|-------------|---------|
| `type:T` | SQL column type | `type:varchar(255)`, `type:timestamptz`, `type:uuid` |
| `pk` | Primary key | `pk` (UUID generated by `BeforeInsert` hook, not `auto`) |
| `notnull` | NOT NULL constraint | `notnull` |
| `default:V` | Default value | `default:active`, `default:current_timestamp` |
| `unique` | Unique constraint | `unique` |
| `index` | Create index | `index` |
| `soft_delete` | Soft delete column | `soft_delete` on `*time.Time` field |
| `scanignore` | Skip scanning | `scanignore` (field won't be read from DB) |

### Relationships

**Belongs To:**

```go
type Item struct {
    BaseModel `bun:"table:items,alias:i"`

    Name     string    `bun:"type:varchar(255),notnull" json:"name"`
    Category *Category `bun:"rel:belongs-to,join:category_id"`
    CategoryID uuid.UUID `bun:"type:uuid" json:"category_id"`
}
```

**Has Many:**

```go
type Category struct {
    BaseModel `bun:"table:categories,alias:c"`

    Name  string         `bun:"type:varchar(255),notnull" json:"name"`
    Items bun.Slice[Item] `bun:"rel:has-many,on:category_id"`
}
```

**Many-to-Many (junction table):**

Use `bun.BaseModel` (not the project's `model.BaseModel`) to avoid an unnecessary `id` column — the composite key `(page_id, tag_id)` is the primary key. Use `column:name,type:uuid,pk` syntax for composite keys (not `pk,type:uuid` which creates a bogus `pk` column):

```go
type PageTag struct {
    // Uses bun.BaseModel (not project BaseModel) to avoid an extra ID column.
    // The composite key (page_id, tag_id) is the primary key.
    bun.BaseModel `bun:"table:page_tags,alias:pt"`
    PageID uuid.UUID `bun:"column:page_id,type:uuid,pk" json:"page_id"`
    TagID  uuid.UUID `bun:"column:tag_id,type:uuid,pk" json:"tag_id"`
}
```

Query with a two-step approach (subqueries via `ColumnExpr` produce `Model(nil)` errors):

```go
// Step 1: Scan junction table
var pageTags []model.PageTag
db.NewSelect().Model(&pageTags).Where("page_id = ?", pageID).Scan(ctx)

// Step 2: Query tags by collected IDs
if len(pageTags) == 0 { return []model.Tag{}, nil }
idList := make([]any, len(pageTags))
for i, pt := range pageTags { idList[i] = pt.TagID }
var tags []model.Tag
db.NewSelect().Model(&tags).Where("id IN (?)", bun.In(idList)).Scan(ctx)
```

### Lifecycle hooks

```go
func (i *Item) BeforeInsert(ctx context.Context) error {
    if i.Status == "" {
        i.Status = "active"
    }
    return nil
}

func (i *Item) BeforeUpdate(ctx context.Context) error {
    i.UpdatedAt = time.Now()
    return nil
}
```

### Query patterns

```go
// Find by ID
var item Item
err := db.NewSelect().Model(&item).Where("id = ?", id).Scan(ctx)
if err != nil {
    if errors.Is(err, sql.ErrNoRows) {
        // not found — use sql.ErrNoRows, not bun.ErrNotFound (doesn't exist)
        return nil, fmt.Errorf("item not found")
    }
    return nil, err
}

// List with pagination — Limit() and Offset() take int64, not int
var items []Item
err := db.NewSelect().Model(&items).
    Order("created_at DESC").
    Limit(int64(limit)).
    Offset(int64(offset)).
    Scan(ctx)

// Create
_, err := db.NewInsert().Model(item).Exec(ctx)

// Update
_, err := db.NewUpdate().Model(item).
    Where("id = ?", item.ID).
    WherePK().
    Exec(ctx)

// Soft delete (bun's soft_delete tag converts this to UPDATE SET deleted_at=now)
_, err := db.NewDelete().Model(item).
    Where("id = ?", item.ID).
    Exec(ctx)
```

### Cross-database compatibility

- Development uses SQLite, production uses PostgreSQL
- Use `type:timestamptz` for timestamps — bun translates to the correct dialect
- Use `type:uuid` — bun handles UUID conversion for SQLite
- Use `gen_random_uuid()` in PostgreSQL migrations; bun's `BeforeInsert` hook generates UUIDs for SQLite

## Gotchas

**Use `Model(&slice)`, not `Model(&[]Type{})`.**

```go
// CORRECT — uses the existing slice variable
var items []model.Item
err := db.NewSelect().Model(&items).Limit(limit).Scan(ctx)

// WRONG — creates a new internal slice; your variable stays empty with no error
err := db.NewSelect().Model(&[]model.Item{}).Limit(limit).Scan(ctx)
var items []model.Item
err = db.NewSelect().Model(&[]model.Item{}).Limit(limit).Scan(ctx)  // items is empty!
```

**Manual JOINs with aliased tables don't resolve aliases.**

If your model has `bun:"table:tags,alias:t"`, the `t` alias is not available in manual JOIN clauses. Use a subquery instead:

```go
// Use a subquery for complex joins
db.NewSelect().Model(&tags).
    Where("id IN (SELECT tag_id FROM page_tags WHERE page_id = ?)", pageID).
    Scan(ctx)
```

**`Limit()` and `Offset()` take `int64`, not `int`.**

Convert explicitly: `db.NewSelect().Model(&items).Limit(int64(limit))`.

**No `bun.ErrNotFound` — use `sql.ErrNoRows`.**

```go
import "database/sql"
if errors.Is(err, sql.ErrNoRows) { /* not found */ }
```

**`Count()` returns `(int, error)`, not just `error`.**

```go
count, err := db.NewSelect().Model(&items).Where("status = ?", "active").Count(ctx)
```

**Build WHERE clauses conditionally for optional filters.**

Never use `Where("field = ?", applyDefault(ptr, ""))` — an empty default filters out all rows. Build the query conditionally:

```go
q := db.NewSelect().Model(&items)
if status != nil && *status != "" {
    q = q.Where("status = ?", *status)
}
if categoryID != nil {
    q = q.Where("category_id = ?", *categoryID)
}
err := q.Scan(ctx)
```

**Tree building — use a map of pointers, not struct copies.**

When building hierarchical trees (e.g., nested categories), use a `map[uuid.UUID]*Node` for lookups and collect roots by checking `parentID == uuid.Nil`. Appending struct copies to a slice loses pointer indirection:

```go
func GetCategoryTree(ctx context.Context) ([]CategoryTree, error) {
    var all []CategoryRead
    db.NewSelect().Model(&all).OrderExpr("name").Scan(ctx)

    byID := make(map[uuid.UUID]*CategoryRead, len(all))
    for i := range all {
        byID[all[i].ID] = &all[i] // pointer into the slice
    }

    var roots []CategoryRead
    for _, c := range all {
        if c.ParentID != nil && *c.ParentID != uuid.Nil {
            if parent, ok := byID[*c.ParentID]; ok {
                parent.Children = append(parent.Children, c)
            }
        } else {
            roots = append(roots, c)
        }
    }
    return roots, nil
}
```

## Key conventions

- Always embed `BaseModel` — it provides ID, timestamps, soft delete
- Always create a migration — never rely on auto-migration in production
- Use explicit column types — no magic type inference
- Keep models in `internal/model/` — one file per model
- Service layer handles queries directly — models define structure, service functions define queries
- Use `sql.ErrNoRows` (not `bun.ErrNotFound`, which doesn't exist)
- `Limit()` and `Offset()` take `int64` — convert explicitly
